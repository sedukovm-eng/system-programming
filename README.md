# Тема: Операційна система GNU/Linux та автоматизація в BASH

## 1. Коротка інформація про ОС GNU/Linux
**GNU/Linux** — це сімейство вільних та відкритих Unix-подібних операційних систем, побудованих на базі ядра Linux та системних утиліт проекту GNU.

### Основні риси:
* **Багатозадачність та багатокористувацька архітектура:** Можливість одночасної роботи багатьох користувачів та процесів з чітким розмежуванням прав доступу.
* **Відкритий вихідний код (Open Source):** Розповсюджується під ліцензією GNU GPL, що дозволяє вільно модифікувати та розповсюджувати код.
* **Надійність та безпека:** Модульна структура ядра та сувора система привілеїв роблять систему стійкою до збоїв та шкідливого ПЗ.
* **Гнучкість:** Використовується на всьому спектрі обладнання — від суперкомп'ютерів, серверів та IoT-пристроїв до персональних комп'ютерів і смартфонів (Android).

## 2. Перелік найбільш популярних дистрибутивів
Дистрибутив Linux — це операційна система, що включає ядро Linux, системне ПЗ GNU, менеджер пакетів та набір прикладних програм.

| Дистрибутив | Базова система | Призначення / Особливості |
| :--- | :--- | :--- |
| **Ubuntu** | Debian | Найпопулярніший дистрибутив для ПК та хмарних серверів. Дружній до новачків. |
| **Debian** | Автономний | Еталон стабільності та надійності. Включно лише з перевіреним вільним ПЗ. |
| **Fedora** | RHEL | Інноваційний дистрибутив із найновішими версіями пакетів, що спонсорується Red Hat. |
| **Arch Linux** | Автономний | Дистрибутив за принципом KISS (Keep It Simple, Stupid) з оновленням Rolling Release. |
| **Manjaro** | Arch Linux | Полегшена та налаштована для робочих станцій версія Arch Linux. |
| **Linux Mint** | Ubuntu / Debian | Чудовий вибір для користувачів, що переходять з Windows (зручний інтерфейс Cinnamon). |
| **Rocky / AlmaLinux** | RHEL | Безкоштовні корпоративні дистрибутиви серверного рівня. |

#!/bin/bash

# Скрипт імітації авторизації в ОС Linux у текстовому режимі (TTY)

# Еталонні облікові дані
VALID_USER="admin"
VALID_PASS="secret123"

# Кольори для оформлення виводу (ANSI escape codes)
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
CYAN='\033[0;36m'
NC='\033[0m' # No Color

MAX_ATTEMPTS=3
attempt=1

clear
echo -e "${CYAN}====================================================${NC}"
echo -e "${CYAN}        СИСТЕМА АВТОРИЗАЦІЇ GNU/LINUX (TTY1)        ${NC}"
echo -e "${CYAN}====================================================${NC}"
echo -e "Вузли системи: ${YELLOW}$(hostname)${NC} \vert{} Дата: $(date '+%Y-%m-%d %H:%M:%S')"
echo -e "${CYAN}----------------------------------------------------${NC}\n"

while [ $attempt -le$MAX_ATTEMPTS ]; do
    echo -e "${YELLOW}[Спроба $attempt з $MAX_ATTEMPTS]${NC}"
    
    # Введення імені користувача
    echo -n "login: "
    read username
    
    # Введення пароля без відображення на екрані (-s)
    echo -n "Password: "
    read -s password
    echo ""
    
    # Перевірка введених даних
    if [ "$username" == "$VALID_USER" ] && [ "$password" == "$VALID_PASS" ]; then
        echo -e "\n${GREEN}[УСПІХ] Авторизація пройшла успішно!${NC}"
        echo -e "${GREEN}Ласкаво просимо в систему, $username!${NC}\n"
        echo "----------------------------------------------------"
        echo -e "Поточний користувач: ${CYAN}$(id -un)${NC} (UID:$(id -u))"
        echo -e "Інформація про ядро: ${CYAN}$(uname -sr)${NC}"
        echo "----------------------------------------------------"
        exit 0
    else
        echo -e "${RED}[ПОМИЛКА] Невірне ім'я користувача або пароль!${NC}\n"
        ((attempt++))
    fi
done

# Якщо спроби вичерпано
echo -e "${RED}====================================================${NC}"
echo -e "${RED} [БЛОКУВАННЯ] Вичерпано ліміт спроб входу!           ${NC}"
echo -e "${RED} Доступ обмежено. Зверніться до системного адміна.   ${NC}"
echo -e "${RED}====================================================${NC}"
exit 1
